# 🎧 DevSongs

Plataforma completa de streaming e licenciamento de músicas para desenvolvedores, inspirada na interface do YouTube Music e Spotify, com suporte a multi-bases, catálogo de faixas, carrosséis dedicados e sistema de compras com cupons e PIX.

## 🛠️ Como Executar o Projeto

### Backend (Node.js / Express)
```bash
cd backend
npm install
npm run dev
```

### Frontend (Next.js / React)
```bash
cd frontend
npm install
npm run dev
```

Acesse no navegador: [http://localhost:3000](http://localhost:3000)
